# Точки самопомощи

Офлайн-справочник (PWA) по самопомощи при мышечных спазмах: триггерные точки и акупрессура.
Нажимаете на зону тела или вводите слово/симптом — получаете пошаговую карточку: где найти точку,
чем давить, как долго, что должно ощущаться и когда нельзя.

> Это инструмент для снятия мышечного напряжения. Не лечение и не диагностика.

Полное ТЗ — в [SPEC.md](SPEC.md).

## Что уже есть (этапы 1–3)

- Каркас PWA: работает без интернета после первой загрузки, ставится на экран «Домой».
- Три входа: силуэт тела (спереди/сзади), поиск по слову, поиск по симптому.
- Карточки: между лопаток (ромбовидные, средняя трапеция), квадрицепс и колено (3 карточки),
  трицепс и локоть, икры (икроножная, камбаловидная), подошва стопы.
- Этап 3: шея (верхняя трапеция, поднимающая лопатку, подзатылочные), плечо (подостная, дельтовидная),
  поясница (квадратная, разгибатели), ягодицы и бедро (средняя ягодичная, грушевидная, задняя поверхность бедра),
  предплечья и кисть (разгибатели, сгибатели, мышцы большого пальца), голова (височная, жевательная).
- Метки «проверено на себе» / «по справочникам», личные заметки, экспорт и импорт заметок в файл.
- Кнопка «Когда срочно к врачу» на каждом экране; раздел составлен по страницам NHS со ссылками.

## Публикация на GitHub Pages

1. Откройте репозиторий на github.com → **Settings** → **Pages**.
2. В блоке **Build and deployment** выберите **Source: Deploy from a branch**.
3. В поле **Branch** выберите ветку с приложением (`main` после слияния, либо рабочую ветку) и папку **/ (root)**, нажмите **Save**.
4. Через 1–2 минуты наверху страницы появится адрес вида `https://<логин>.github.io/aleks_med/`.

Репозиторий должен быть публичным (на бесплатном тарифе Pages работает только так). Личные заметки в репозиторий
не попадают — они хранятся только в телефоне.

## Установка на iPhone

1. Откройте адрес сайта именно в **Safari** (не в Chrome и не во встроенном браузере мессенджера).
2. Дождитесь, пока главный экран загрузится полностью, и откройте одну любую карточку.
3. Нажмите кнопку **Поделиться** (квадрат со стрелкой вверх) → **На экран «Домой»** → **Добавить**.
4. Запускайте приложение с иконки «Точки» на экране «Домой».

### Проверка в режиме полёта

1. Откройте приложение с иконки один раз при включённом интернете (при первом запуске оно скачивает всё в кеш).
2. Закройте приложение (смахните его из списка открытых).
3. Включите **Авиарежим**, убедитесь, что Wi-Fi тоже выключен.
4. Откройте приложение с иконки. Проверьте: главный экран с силуэтом, поиск («колено»), 2–3 карточки
   со схемами, раздел «Когда срочно к врачу», заметку в карточке.
5. Выключите авиарежим.

Если без сети открылся пустой экран — включите интернет, откройте приложение, подождите 10 секунд и повторите.

### Резервная копия заметок

iOS может очистить данные сайта, если приложением долго не пользоваться. Раз в какое-то время:
**Заметки ⚙︎ → Экспорт заметок в файл → Сохранить в Файлы**. Восстановление — там же, «Импорт заметок из файла».

## Как править без установки чего-либо

Сборки нет: чистые HTML/CSS/JS, данные в JSON. Файлы можно править прямо на github.com (карандаш в углу файла).

| Что | Где |
| --- | --- |
| Тексты карточек, симптомы, общие правила | `data/cards.json` |
| Раздел «Когда срочно к врачу» | `data/doctor.json` |
| Экраны и логика | `index.html`, `js/app.js`, `css/style.css` |
| Силуэт тела и зоны главного экрана | `js/body.js` |
| Схемы карточек | `svg/*.svg` |
| Офлайн-кеш | `sw.js` |

После правки изменения появляются в установленном приложении **со второго открытия** при наличии интернета:
первый запуск показывает старую версию из кеша и в фоне скачивает новую.

Перевести карточку в «проверено на себе» для всех устройств: в `data/cards.json` заменить у неё
`"status": "reference"` на `"status": "verified_self"`. Для себя это делается одним нажатием на метку в карточке.

### Схемы

Файлы `svg/*.svg` и `icons/icon.svg` сгенерированы скриптом `tools/build-svg.js` из общего силуэта (`js/body.js`):
мышца, точки и зона боли заданы в нём координатами. Перегенерация: `node tools/build-svg.js` (нужен только Node.js,
пакеты не нужны). PNG-иконки — `node tools/build-icons.js` (нужен Playwright). Приложению эти скрипты не нужны.

## Источники и ограничения

- Карточки написаны своими словами. Travell & Simons «Myofascial Pain and Dysfunction» и Davies
  «The Trigger Point Therapy Workbook» использованы только как ориентир; тексты и рисунки не копировались.
- Схемы — собственные SVG. Реалистичные рендеры (Anatomography/BodyParts3D, Z-Anatomy) возможны позже,
  с указанием источника и лицензии CC BY-SA.
- «Когда срочно к врачу» — перевод и пересказ страниц NHS (nhs.uk); ссылки и даты редакций указаны в самом разделе.
- Доказательная база триггерных точек неровная; приложение не обещает лечения и не заменяет врача.
